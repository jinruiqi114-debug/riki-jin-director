# riki-jin-director

Riki Jin 电影情绪导演系统。它不是单纯的提示词润色器，而是先判断创作任务，再把人物情绪、动作因果、镜头节奏、空间关系和声音设计组织成可执行、可直接复制生成的提示词。

Seedance 规则以字节跳动官方 AgentKit 示例为底座，Midjourney 方法参考公开社区资料；核心创作判断来自 Riki Jin 的个人电影情绪风格。

## 能做什么

- 将一句创意扩展为 logline、人物卡、节奏结构和分镜
- 路由 Seedance 新视频生成、自然延长和视频编辑任务
- 生成可直接复制的单镜头或多段视频提示词
- 统一角色、服装、道具、镜头和声音的连续性
- 将长剧情拆成短片、短剧、广告、动画或预告片
- 评审并改写空泛、冲突或不可执行的提示词
- 将电影情绪风格转化为 Midjourney 图像提示词
- 拆解现成的 Midjourney 提示词，分析影调、质感、真实感、主体特征、光影、色彩、构图和参数
- 在拆解后生成一条保留原视觉意图的中文版试验提示词，用于验证中文表达效果
- 用户回复 `ok` 后直接输出对应的英文完整版 Midjourney 提示词
- 在提示词过长、动作过密、时长不足或逻辑冲突时主动提醒
- 将长镜头拆成约 15 秒的连续短镜头，并写清衔接状态

## 安装

将本仓库作为 Skill 使用，入口文件为 `SKILL.md`。也可以下载 `.skill` 打包文件后导入 Manus。

## 示例请求

> 把“一个外卖员在暴雨夜送达最后一单”做成 9:16、15 秒、三镜头短视频提示词，要求有悬念和温暖结尾。

> 评审这段 AI 视频提示词，指出角色连续性和镜头动作问题，并给出修改版。

> 这不是视频编辑任务，以 00:13–00:15 为边界向后自然延长 8 秒，不重复原片内容。

> 拆解这条 Midjourney 提示词，分别说明它的影调、质感、真实感、人物特征、光影、构图和参数，并提炼可复用的关键词。
