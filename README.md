# riki-jin-director

Riki Jin Midjourney 提示词拆解系统。它专门分析现成的 Midjourney 静态图像提示词，帮助你理解关键词如何影响画面、发现视觉冲突、提炼可复用词组，并生成中文版试验提示词。

本仓库**不包含 Seedance、视频生成、视频编辑、视频延长、剧本写作或视频分镜功能**。

## 核心能力

- 保留并分段解析原始 Midjourney 提示词
- 从主体特征、影调、质感、真实感、光影、色彩、构图、镜头感、情绪、环境和参数等维度拆解
- 区分原文明确要求、视觉推断、信息缺失和潜在冲突
- 检查主体数量、视线、构图、光源方向、媒介、色彩和参数之间的一致性
- 提炼不依赖特定艺术家姓名的可复用视觉关键词组
- 拆解完成后生成一条忠实原意的中文版试验提示词
- 用户回复 `ok` 后直接输出对应的英文完整版
- 用户明确要求时，再生成正式优化版；默认不擅自改写原提示词

## 使用示例

```text
拆解这条 Midjourney 提示词，分别说明它的影调、质感、真实感、主体特征、光影、色彩、构图、情绪和参数，并生成一条中文版试验提示词。
```

```text
分析这条 Midjourney 提示词有哪些视觉冲突，提炼出可复用的光影、色彩和构图词组。
```

完成拆解后，系统会提示：

```text
回复 ok 获取英文完整版。
```

## 安装

将本仓库作为 Skill 使用，入口文件为 `SKILL.md`。也可以下载 `.skill` 打包文件后导入 Manus。

## 目录

- `SKILL.md`：Midjourney-only 的任务边界、拆解工作流和输出格式
- `references/midjourney-prompt-methods.md`：图像提示词结构、情绪转译和迭代反馈方法
- `references/midjourney-prompt-decomposition.md`：多维拆解定义、冲突检查、中文试验提示词与 `ok` 快捷规则
- `LICENSE`：MIT 许可证
