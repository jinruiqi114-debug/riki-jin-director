# riki-jin-director

Riki Jin Midjourney 提示词拆解 Skill。用于分析现成的 Midjourney 静态图像提示词，解释关键词如何影响画面，检查视觉冲突，提炼可复用词组，并生成中文版试验提示词。

## 功能

- 按主体、影调、质感、真实感、光影、色彩、构图、镜头感、情绪、环境和参数拆解提示词
- 区分原文明确要求、视觉推断、信息缺失和潜在冲突
- 检查主体、光源、构图、媒介、色彩和参数的一致性
- 提炼可迁移的视觉关键词组
- 生成忠实原意的中文试验提示词
- 回复 `ok` 后直接输出对应的英文完整版

## 使用

将提示词和任务一起发送，例如：

```text
拆解这条 Midjourney 提示词，说明它的影调、质感、真实感、主体特征、光影、色彩、构图、情绪和参数，并生成中文版试验提示词。
```

完成后回复：

```text
ok
```

即可获得英文完整版提示词。
