# riki-midjourney

Riki Jin Midjourney 提示词分析 Skill。用于客观拆解现成的 Midjourney 静态图像提示词，也可以根据参考图片反向拆解视觉维度，并生成中文版试验提示词。

默认只做分析，不主动排查问题、评价好坏、提出修改建议或优化方案。只有用户明确要求时，才执行排查、检查、优化或修改。

## 功能

- 按主体、影调、质感、真实感、光影、色彩、构图、镜头与焦距、景深、情绪、环境和参数拆解提示词
- 根据参考图片拆解主体层级、景别、视角、空间关系、镜头与焦距倾向、透视、景深、光线、影调、色彩、材质、空气透视和画幅
- 区分图片中的可见信息、合理推断和无法确定的信息，不声称还原原始提示词
- 区分原文明确要求、视觉推断和信息缺失
- 提炼可迁移的视觉关键词组
- 生成忠实原意的中文试验提示词
- 回复 `ok` 后直接输出对应的英文完整版
- 用户要求诊断或优化时，先说明问题，再输出完整可复制的最终提示词，不只提供局部修改片段
- 遇到大型复杂场景时，先提醒可能不稳定的部分；用户同意后再重写提示词

## 使用

```text
分析这条 Midjourney 提示词，分别说明它的影调、质感、真实感、主体特征、光影、色彩、构图、情绪和参数，并生成中文版试验提示词。
```

也可以上传一张参考图并说：

```text
根据这张图拆解 Midjourney 提示词，分别分析构图、主体关系、镜头、影调、光影、色彩、质感、空气透视和环境，然后生成中文版试验提示词。
```

完成后回复：

```text
ok
```

即可获得英文完整版提示词。
