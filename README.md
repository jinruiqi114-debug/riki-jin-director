# riki-jin-director

Riki Jin Midjourney 提示词分析 Skill。用于客观拆解现成的 Midjourney 静态图像提示词，说明关键词如何影响画面，并生成中文版试验提示词。

默认只做分析，不主动排查问题、评价好坏、提出修改建议或优化方案。只有用户明确要求时，才执行排查、检查、优化或修改。

## 功能

- 按主体、影调、质感、真实感、光影、色彩、构图、镜头感、情绪、环境和参数拆解提示词
- 区分原文明确要求、视觉推断和信息缺失
- 提炼可迁移的视觉关键词组
- 生成忠实原意的中文试验提示词
- 回复 `ok` 后直接输出对应的英文完整版
- 用户要求诊断或优化时，先说明问题，再输出完整可复制的最终提示词，不只提供局部修改片段
- 遇到大型复杂场景时，先提醒可能不稳定的部分；用户同意后再重写提示词

## 使用

```text
分析这条 Midjourney 提示词，分别说明它的影调、质感、真实感、主体特征、光影、色彩、构图、情绪和参数，并生成中文版试验提示词。
```

完成后回复：

```text
ok
```

即可获得英文完整版提示词。
