# Midjourney 分析参考

## 分析原则

拆解现成提示词，不是逐词翻译，也不是无依据地扩写。先保留原文，再说明关键词如何共同构成画面。所有信息分为：

- **明确**：原文直接写出。
- **推断**：由关键词组合推导出的视觉倾向。
- **缺失**：原文没有提供，不补充为事实。

## 维度速查

1. **主体与特征**：数量、身份、外观、姿态、表情、动作、材质和识别锚点。
2. **影调**：亮度、反差、黑位、白位、雾感和压迫感。
3. **质感与媒介**：材质、胶片颗粒、纸张、绘画笔触、摄影或 3D 质感。
4. **真实感**：纪实、电影写实、超写实、商业摄影、插画、CG 或超现实，以及原文依据。
5. **光影**：光源方向、色温、硬软、阴影、轮廓光、反射和遮挡。
6. **色彩**：主色、辅色、饱和度、明度和冷暖关系。
7. **构图与摄影感**：主体位置、留白、前中后景、焦点、画幅、焦段、景深和虚化。
8. **情绪氛围**：情绪词对应的姿态、空间、色彩和光线表达。
9. **环境**：时间、地点、天气、建筑、道具和空间关系。
10. **参数**：画幅、版本、风格化程度、混沌度、图像权重和约束；只说明原文中出现的参数。

## 中文试验提示词

中文试验版保持原意和视觉结构，按以下顺序组织：

`主体与状态 → 场景 → 构图与摄影感 → 光影与色彩 → 质感与媒介 → 情绪 → 原文约束 → 参数`

不要添加原文没有的角色、道具、地点、剧情或声音。原文没有提供的信息保持缺失。参数原样放在末尾。
